# Speaker Script Style Standard

Use this standard whenever generating or revising read-ready speaker scripts, slide notes, panel answers, or presentation narration.

## Purpose

Explain the slide clearly and directly.

## Tone

Clear, concise, professional, and spoken naturally. The script should sound like something a presenter would actually say aloud.

## Style Rules

- Get straight to the point.
- Use short sentences.
- Avoid academic-sounding transitions or abstract framing.
- Do not use phrases like "This slide marks..." or "At the heart of the module..."
- Focus on the main contrast, decision, or takeaway.
- End each slide script with one strong takeaway sentence.

## Quality Check

Before finalizing, read each script aloud. If it sounds written for a paper instead of spoken by a presenter, revise it.
